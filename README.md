# Заводская смена

[Скачать игру ZIP](https://github.com/Igor-Afanasev/game/raw/refs/heads/main/downloads/factory-shift.zip) — распакуйте и откройте `play.html` в браузере.

Доведите Игоря (специалист ОИ), Ивана (специалист ОИ) и Николая (специалист) до автомобильной покрышки внизу справа. Победа засчитывается только после финиша всех троих. Соберите каждому по 3 бургера и 3 пирожка: максимум команды — 18/18. Финишировать можно с любым запасом.

## Запуск

Распакуйте архив и откройте **play.html** обычным браузером. Это автономная версия без дополнительных файлов и установки. Не открывайте её в предпросмотре файлов или внутри ZIP — там JavaScript может не выполняться.

Альтернатива: откройте index.html, сохранив рядом game.js. Для разработки можно запустить `python3 -m http.server 8000` из папки игры.

## Управление

- WASD / стрелки — движение.
- C / «Смена персонажа» — следующий незавершивший миссию герой.
- F / «Удар» — атака в радиусе 65, задержка 0,45 секунды.
- E / пробел — памятка задания.
- P — пауза. При потере фокуса игра автоматически ставится на паузу.

У каждого героя отдельные положение, здоровье и еда. Неактивные герои ждут на месте и не получают урон. После финиша управление автоматически переходит к следующему. Еда восстанавливает одно здоровье до максимума 5; полученный урон не уменьшает счёт еды. При поражении активного героя нужно начать всю смену заново. Прогресс не сохраняется после закрытия страницы.

## Тезка

Надзиратель патрулирует оба участка завода, обходит здания и использует переход. Радиус обнаружения — 320, прекращения погони — 420. Скорость патруля — 130, погони — 180, коротких рывков — 208 (герой — 195). Маршрут обновляется каждые 0,15 секунды. У Тезки 6 здоровья. После победы над ним есть 12 секунд до его возвращения. Контакт наносит урон, после которого герой защищён 1,2 секунды.

index.html и game.js — исходники; play.html — автономная копия. После изменения исходников пересоберите play.html, заменив подключение game.js его содержимым внутри тега script.
