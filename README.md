# Хранители долины — гонка за припасами

Миссия: добраться до финиша в виде автомобильной покрышки внизу справа с максимальным количеством еды. На карте три бургера и три пирожка. Лучший результат — 6/6, но финишировать можно с любым запасом. Итоговый экран показывает общий результат и количество каждого вида еды.

Бургеры лежат слева от реки, пирожки — справа. Мост открыт сразу. Еда собирается при приближении, восстанавливает одно очко здоровья (максимум 5) и остаётся в счётчике после получения урона. Игорь и Иван — специалисты ОИ, Николай — специалист; они дают подсказки, разговоры необязательны.

Надзиратель Тезка патрулирует карту, обходит здания и преследует героя, заметив его в радиусе 165 игровых единиц. Можно убежать (герой быстрее; погоня заканчивается на расстоянии 250) или победить четырьмя ударами. F наносит удар в радиусе 65 единиц с задержкой 0,45 секунды. Контакт с Тезкой отнимает здоровье, после попадания действует защита 1,2 секунды. При нулевом здоровье миссия проиграна, доступен перезапуск.

## Запуск

Без зависимостей и сборки: откройте `index.html` в браузере или выполните:

```sh
cd /workspace/game
python3 -m http.server 8000 --bind 0.0.0.0
```

WASD / стрелки — движение, E / пробел — диалог, F — удар, P — пауза. Есть экранные кнопки. При потере фокуса игра ставится на паузу. Прогресс хранится только до перезагрузки или новой игры.
